MCP install

The AAAA-Nexus MCP server puts the Atomadic API in your editor as nexus_* tools.

AAAA-Nexus is a hosted HTTP API for agent trust: hallucination and drift verdicts, compliance certificates, escrow, provenance-gated retrieval, and randomness. The MCP server is a thin local wrapper around it. Your calls go to https://atomadic.tech; nothing is executed on your machine but the wrapper.

1. Install

pip install aaaa-nexus-mcp

Requires Python 3.12 or newer. This installs the mcp SDK as a dependency.

2. Point your editor at it

Claude Code, Cursor, Claude Desktop, VS Code, Zed and Windsurf all take the same server block. Put this in your MCP config (~/.claude/settings.json, project .mcp.json, or the editor's equivalent):

{
  "mcpServers": {
    "aaaa-nexus": {
      "command": "python",
      "args": ["-m", "aaaa_nexus_mcp"],
      "env": {
        "AAAA_NEXUS_API_KEY": "an_your_key_here",
        "AAAA_NEXUS_AUTOGUARD": "1"
      }
    }
  }
}

Restart the editor. The tools appear prefixed nexus_.

No key yet? Delete the AAAA_NEXUS_API_KEY line. The free endpoints below work without one, and the paid tools will tell you what a call costs.

3. Configuration

AAAA_NEXUS_API_KEYnoneBearer token for paid tools
AAAA_NEXUS_BASE_URLhttps://atomadic.techAPI base URL
AAAA_NEXUS_TIMEOUT20.0Request timeout in seconds
AAAA_NEXUS_AUTOGUARD1Annotate every response with hallucination and drift verdicts

4. Free endpoints, no key

  • https://atomadic.tech/health — service health and build stamp
  • https://atomadic.tech/v1/rng/quantum — quantum-seeded random bytes
  • https://atomadic.tech/v1/metrics — live platform metrics

5. First call without the plugin

If you would rather skip MCP entirely, the same surface is plain HTTP:

curl -sS https://atomadic.tech/v1/oracle/hallucination \
  -H "Authorization: Bearer $AAAA_NEXUS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text":"The moon is made of Swiss cheese."}'

Every response carries a _guard block with hallucination and drift verdicts.

6. Keys and pricing

Paid calls are metered per call in USDC on Base (x402) or against a credit pack. Get a key at atomadic.tech/pay. Per-endpoint prices are published at /.well-known/pricing.json.

If something breaks

Open an issue at github.com/atomadictech/atomadic-mcp with the tool name, the request body and the response. Include the x-request-id header if you have it; that is the fastest way to trace a call.
